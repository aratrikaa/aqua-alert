How AquaAlert Works

An end-to-end AI pipeline for groundwater risk classification in India

Data Layer

Monthly groundwater depth (mbgl) and rainfall (mm) for 12 districts across Punjab, Rajasthan, and Maharashtra. Data mimics CGWB/IMD seasonal patterns including monsoon recovery cycles (2019–2024).

Feature Engineering

  • Rainfall lags: 30 / 60 / 90 day
  • Pre-monsoon vs post-monsoon depth
  • Monsoon recharge recovery delta
  • Annual depletion trend (linear slope)
  • Extraction rate proxy (0–1)
  • Current water table depth

ML Classification

Random Forest (baseline) and XGBoost classifiers are trained and cross-validated. The best model is selected automatically. Output classes: Safe Moderate Critical

Explainability (SHAP)

TreeSHAP computes per-prediction feature contributions. The top 3 driving factors are surfaced in plain language — e.g. "Flagged Critical due to rapid annual depletion trend, severe pre-monsoon water table drop, and high groundwater extraction."

Connecting Real Data

Replace data/groundwater_timeseries.csv with CGWB dynamic groundwater level data and IMD gridded rainfall in the same schema. Delete model/aqua_model.joblib to trigger re-training. See the README for details.

Tech Stack

  • Backend: Python · Flask
  • ML: scikit-learn · XGBoost
  • Explainability: SHAP
  • Maps: Leaflet.js
  • Charts: Chart.js
  • Fonts: Inter (Google Fonts)
